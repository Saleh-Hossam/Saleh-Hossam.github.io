📦 Supply Chain Root Cause Analysis

SQL Server Power BI Data Analysis Root Cause Analysis

Business Challenge: Investigate inventory discrepancies that were impacting supply chain efficiency and customer satisfaction.

Used SQL for multi-dimensional aggregation and Power BI for visualization. Initially suspected late deliveries (20% of orders) were the problem, but analysis revealed inventory loss (5% of orders) was actually responsible for 32,000+ units in discrepancies—a classic case where data challenged assumptions.
